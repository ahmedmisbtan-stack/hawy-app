# هاوي — Hawy

منصة عربية تجمع مقدمي الخدمات وأصحاب المشاريع الصغيرة بالعملاء داخل مجتمع واحد.

## الموجود حاليًا

- واجهة عربية RTL متجاوبة للموبايل والويب.
- وضع غامق مع التبديل التلقائي للوضع الفاتح حسب إعدادات الجهاز.
- اكتشاف الخدمات حسب الفئة، البحث النصي، وفلاتر المنطقة.
- بطاقات متاجر تجريبية مع تقييمات ومفضلة ونافذة تفاصيل.
- واجهة مجتمع ومنشورات تجريبية وتفاعلات محلية.
- صفحة محفظة تجريبية توضّح حالة الرصيد دون تنفيذ معاملات مالية.
- تنقل سفلي للموبايل وتصميم مخصص للشاشات الكبيرة.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## حالة التنفيذ

**هذه مرحلة واجهة أولية (UI prototype)، وليست خدمة إنتاجية مكتملة.** البيانات الحالية تجريبية، وبعض الأزرار تعرض توضيحات بدلًا من تنفيذ عمليات خلفية. لا توجد حاليًا مصادقة مستخدمين، قاعدة بيانات، محادثات حقيقية، نظام طلبات، صلاحيات خصوصية مفروضة على الخادم، أو تكامل دفع/محفظة مالية.

## خارطة طريق المنتج

تم توثيق الرؤية وتقسيم التنفيذ إلى مراحل في [`docs/PRODUCT_ROADMAP.md`](docs/PRODUCT_ROADMAP.md). بدأت المرحلة الأولى بتوسيع فئات الاكتشاف وأمثلة المتاجر والمنشورات لتشمل المشاريع المنزلية والحرفية، مثل الهاند ميد والكروشيه والديكور وتنظيم الحفلات والملابس والإكسسوارات والهدايا والفنون.

مخطط الكيانات والصلاحيات المقترح موثق في [`docs/DATA_MODEL.md`](docs/DATA_MODEL.md)، ويغطي الحسابات والخصوصية والمتاجر والمنشورات والطلبات والتقييمات والمراسلة ودفتر القيود المالي.

## المراحل التالية

1. اعتماد تصميم الواجهة واختبار تجربة الاستخدام على الموبايل.
2. تحديد البنية الخلفية ومخطط البيانات والصلاحيات.
3. التسجيل وتسجيل الدخول والتحقق من الحسابات.
4. ملفات المستخدمين والمتاجر والخدمات ومعرض الأعمال.
5. المتابعة والمنشورات والتعليقات والتقييمات والإبلاغ والحظر.
6. الطلبات وحالاتها والإشعارات.
7. تصميم دفتر قيود مالي للمحفظة والعمولات والتسويات، ثم تكامل مزود الدفع بعد التعاقد والتحقق من المتطلبات القانونية والأمنية.
8. إعدادات الخصوصية مع تطبيقها فعليًا في API وقواعد البيانات.
9. الاختبارات الآلية، فحص الأمان، وإعدادات النشر.

## ملاحظات

- لا تضع مفاتيح سرية أو بيانات دفع في الواجهة الأمامية.
- صور Unsplash والخطوط الخارجية مستخدمة للعرض التجريبي فقط.
- لا تعتمد على تقييمات أو بيانات العينة لاتخاذ قرارات تجارية حقيقية.
